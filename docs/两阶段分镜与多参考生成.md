# 两阶段分镜与多参考生成（2026-10-11）

新版项目顺序：01剧本分析 → 02分镜确认 → 03自动生成提示词 → 04参考图 → 05视频制作 → 06系统日志。

## 分镜与提示词分离

剧本分析只拆分3–12秒的镜头内容、原文、场景、动作、对白、起止状态和核对提醒。不输出视频提示词、参考图计划或工作流决策。

采纳全部分镜后，自动调用 `/api/prompts` 规划视频提示词和参考图。保留原分镜编号、内容、时长和起止状态，所有视频使用Ref2VA。提示词自动生效，可直接编辑；修改分镜会使旧提示词失效，修改有效提示词后直接生效。两类分析均有5分钟请求超时和取消入口，失败保留原结果。

人物、场景、道具基础母版独立生成。服装与身体状态变体仅依赖明确指定母版，不自动规划逐段首尾帧；每段绑定1–9张已采用参考图，按实际绑定顺序编译图片职责。

## 视频采样

- 标准20步：Ref2VA主模型，不加载加速LoRA。
- 加速8步：Ref2VA专用Acc LoRA，强度1，Euler/simple，视频sigma shift 12、音频3。
- 两种模式共享Ref2VA提示词结构，无需因采样步数变化重写提示词。
- 预览、逐段验收、重做、合片流程保留。

加速文件：`MiniMax-H3-Ref2VA-Acc-8Step_pruned_comfy.safetensors`，位于Director的 `ComfyUI/models/loras`，大小1725921392字节，SHA-256：`6f18e1c2eccb14b37322607730f26b16bf1169b56cd098ea006cffaec43d1e39`。已对照作者Hugging Face文件LFS校验值。使用现有原生PDD支持及 `MiniMaxH3SigmaShift`，无需旧版PDD节点。

来源：[阿里云Acc说明](https://huggingface.co/alibaba-pai/MiniMax-H3-Acc-LoRAs/blob/main/README.md)、[Kijai转换权重](https://huggingface.co/Kijai/MiniMax-H3-experimental/tree/main/loras)、[ComfyUI原生PDD支持](https://github.com/Comfy-Org/ComfyUI/pull/15908)。

分镜规划支持3秒，但当前Director使用24fps、17k+5帧网格，最低107帧，约4.46秒。界面显示计划时长和实际输出时长；不是精确3秒输出。整片总时长按实际帧数累加。
