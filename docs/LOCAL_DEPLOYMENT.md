# 本地部署手册

## 最快启动

1. 安装 Node.js 22.13 或更高版本。
2. 启动本机 ComfyUI，并确认端口为 8188。
3. 双击仓库根目录的 `start-local.cmd`。
4. 浏览器会自动打开 `http://127.0.0.1:3000`。
5. 关闭启动窗口即可停止服务。

首次启动会安装依赖并构建，所需时间较长；以后启动会复用依赖，并且只在源代码比构建产物更新时自动重建。

## 启用 AI 导演分析

第一次双击启动脚本时会自动从 `.env.example` 创建 `.env.local`。在 `.env.local` 中填入：

```text
OPENAI_API_KEY=你的密钥
OPENAI_MODEL=gpt-5.4-mini
```

密钥只由本机服务读取。不要把 `.env.local` 发给别人、粘贴进网页或聊天窗口，也不要提交到 Git。保存后关闭启动窗口并重新双击 `start-local.cmd`；不需要重新构建。

未设置密钥时仍可使用本地规则草稿模式，但人物关系、空间语义和素材冲突判断能力会明显弱于结构化模型分析。

页面右上角会显示 `AI · 模型名` 或 `离线规则`，可直接确认当前服务是否读取了配置。这个状态接口只返回“是否已配置”和模型名，永远不会返回密钥内容。

## ComfyUI 工作流要求

- 必须是 `Save (API Format)` 导出的 JSON。
- 工作流应先在同一台 ComfyUI 上成功运行一次。
- 工作流至少包含一个可写入提示词的 H3/多行文本节点以及 `SaveVideo`。
- 模型文件名和自定义节点版本必须与当前 ComfyUI 一致。
- 参考图按照工作流中 `LoadImage` 节点顺序绑定，最多 8 张，每张不超过 20MB。

## 安全边界

- Web 服务只绑定 `127.0.0.1`，不会开放到局域网或公网。
- ComfyUI 代理只接受 `localhost`、`127.0.0.1` 和 `::1`。
- 项目草稿保存在浏览器本机；API Key 不保存到浏览器。
- 视频生成必须由用户点击单 Beat 按钮触发，运行期间禁止重复提交。
