# Qwen Image 2.1 提示词校准（2026-10-06）

## 依据与范围

优先依据 Qwen 2.1 专属提示词增强器，而不是把百炼其他版本的 API 限制当成本地模型限制：
- https://huggingface.co/Qwen/Qwen-Image-2.1-PE-T2I/blob/main/system_prompt.txt
- https://huggingface.co/Qwen/Qwen-Image-2.1-PE-I2I/blob/main/system_prompt.txt
- https://huggingface.co/Comfy-Org/Qwen-Image-2.1

这是应用规则适配，并未安装或调用官方 PE 模型，也没有视觉读取输入参考图。人物数量、单画面定妆和剧本连续性是项目约束。官方 PE 的固定长篇幅、自动画幅选择未照搬：应用保留剧本证据与现有低显存画幅策略。

## 已落地

在线分析生成无参考图母版时：英文自然段描述完成画面，保留指定数量、颜色、位置、服装材质与照明；不写过程、声音、对白和质量口号。尺寸从独立字段传递。编辑图采用中文操作指令，实际编号由提交器注入。

本地 Qwen 提交器：单图称输入图像，多图逐一使用 <image1> 等标记。每图分别说明身份、空间、道具或状态职责。首帧/状态图可作为局部编辑画布；场景母版允许添加目标角色；仅身份参考时允许新构图，不强锁定定妆照背景和站位。目标变化优先于保留约束，身份参考不重新设计五官。第一输入仍决定当前本地编辑工作流的输出画幅。

离线规则草稿：去掉固定东方题材和排斥现代西装的规则；现代书房、衬衫等证据可进入设定；身份母版不主动叠加临时伤势和湿衣。首尾帧优先读取起止状态。离线草稿仍为中文，并可能在缺失起止状态时引用摘要，需人工校对，不宣称等同官方 PE 生成结果。

百炼、Seedream 的运行时参考图包装保持独立，本次没有把本地 <imageN> 语法强行写入它们的提交器。已缓存提示词与已采用图片不自动迁移；新分析与下一次本地提交使用新规则。

## 示例：双人首帧

编辑目标：把两名角色放入书房，成年男性坐在桌子左侧，成年女性坐在右侧。合上的深蓝笔记本位于男性面前。两人看向对方，双手处于静止姿态。参考职责：<image1> 提供书房空间；<image2> 提供男性身份；<image3> 提供女性身份。保持参考人物身份及场景地标，按目标添加两名角色。

尾帧编辑目标：将画布中的笔记本变为打开状态，空白第一页位于女性面前；人物身份、座位、机位与光线保持一致。这里只描述结束画面，不要求一张图片完成推本子、开本子、说话的全过程。

## 验证与限制

30 项单元测试和 TypeScript 检查通过；新增验证覆盖空场景添加人物、多图编号、单图引用、编辑与保留冲突、现代题材与身份状态分离。未提交真实生图，最终身份与动作状态仍需人工看图验收。当前整片任务不受影响。
